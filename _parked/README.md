# Parked knowledge

These files are complete and accurate. They are held out of the active knowledge base
because **Category Read is currently scoped to beauty and personal care only.**

Depth in one category beats thin coverage of many, and a beauty brand should not get an
answer that reaches for a food and beverage example.

Held here:

- `wellness/supplements-and-ingestibles.md`
- `wellness/functional-food-and-beverage.md`
- `wellness/womens-health.md`

**To bring any of them back:** move the file into `knowledge/`, add it to the file list
in `scripts/build-bundle.sh`, add it to `manifest.json`, rebuild the bundle, and update
the coverage lines in `README.md`, `SKILL.md` and `SETUP.md`.
